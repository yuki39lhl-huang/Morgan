## 冬之女王 · 角色详情与个人资料

### 角色详情

支配异闻带·妖精国不列颠的女王。在异闻带建立绝对王政，用长达约 2000 年的压迫折磨妖精们。身为最高位妖精，是以魔术形式掌握止境之枪·伦戈米尼亚德的神域级天才魔术师。

### 个人资料要点

**资料 1（基础）**  
身高／体重：170cm·56kg。出处：亚瑟王传说、英国妖精史及异闻带不列颠。地域：止境的奥克尼。属性：秩序·恶 / 地 / 女性。  
古代英国妖精史中曾被描写为「善良的湖中妖精」，亚瑟王传说编纂后被视为与亚瑟敌对的恶女；亦与赐予并守护亚瑟的湖中妖精薇薇安被视为同一存在。

**资料 2（泛人类史侧写）**  
泛人类史中为廷塔杰尔之女、伊格蕾因所怀的妖精之子（不列颠岛之子），与阿尔托莉雅成形式上姊妹。自认才是继承神秘的「真王」，憎恨尤瑟、阿尔托莉雅与不服从的人类，成为不列颠破灭的要因之一。子女中圆桌骑士辈出；莫德雷德为其以阿尔托莉雅之血精制造、用以打倒阿尔托莉雅的人工生命。

**资料 3（技能）**  
- **渴望的魅力 B**：历经失败与绝望后，选择以恐怖支配的王者之力。  
- **湖之加护 C**：湖中妖精加护；因流浪过久而降阶。（通关 No.6 后可强化为「阿瓦隆的妖精」）  
- **来自止境 A**：数度濒死仍站起、抵达止境之岛并重返不列颠的女王矜持；仅异闻带之王摩根所有，是冬日风暴具现的诅咒漩涡。

**资料 4（宝具）**  
『业已无法抵达的理想乡』Roadless Camelot（EX / 对城）  
耗尽一生却未能入城的白垩卡美洛——人理不曾让她成为不列颠之王。无法实现的愿望化为哀叹与憎恨。她要打倒的并非亚瑟，而是一度欲毁灭岛上妖精的命运本身，即「人理」。

**资料 5–6（性格）**  
只信自己力量的冷酷女王：并非不信他人，只是不指望。以「有秩序地支配不列颠」为第一。  
讨厌人类与妖精、弱小与丑陋、平等与和平——在民众眼中近乎「恶的化身」。但「讨厌」不等于「不需要」，只是「无法相容」。对她而言，正义＝支配的状态，恶＝扰乱支配者存在；个人好恶与支配者善恶无关。  
漫长守护使心冻结，唯一仍能驱动她的热情，是「支配不列颠」。异闻带的她在千年旅途中抹去了泛人类史模板式的恶女要素，成为收锋的才女；被逼入绝境时，旧日残忍仍可能复燃。

## 救世主梣 · 角色详情与个人资料（通关 No.6）

### 角色详情

这是童年时做的梦——爱着温和善良故事的雨之国魔女的故事。身为妖精却自学诸多魔术，身为公主却驰骋原野热爱冒险的少女；也是迟早会邂逅、离弃、背叛众多命运的救世主最初形象。

### 个人资料要点

**资料 1（基础）**  
属性随灵基变化：秩序·善（雨之魔女）／秩序·中庸（救世主）／秩序·夏（水妃，友情出演）。唯「秩序」不可动摇。

**资料 2（技能）**  
- **雨之国的妖精 A**：深闺大小姐式求知欲与「自己的行动必正确」的明朗确信。  
- **逆境的魅力 A**：总在弱小受虐者面前颠覆劣势，如希望本身。  
- **最后的度假胜地 A**：最后王牌，亦是建造最高级乐园的政治手腕与攻击性结界。

**资料 3（宝具）**  
- 『圣剑遥远梦之遗痕』Memory of Londinium（A++）：梦见的理想乡伦蒂尼恩残骸；唤出本应集结于此的骑士之辉光兵器并使之消散（灵基一、二）。  
- 『孵化希望夏之水镜』Summer Pool Dozmary（A++）：以湖为触媒量产拟似圣剑（灵基三）。

**资料 4（救世主时期）**  
介入氏族争斗、拯救下级妖精而扬名的乐园妖精。称呼由「魔女」变为「救世主」后，才启用养母所赐之名「梣」——尚被视为坏人时不愿用。  
内心仍燃着奥克尼被毁的怒与恨，却以正义、公平与意志压制负面情感。对弱小妖精与奴隶人类而言即是希望：平定纷争、组建圆桌、调停氏族、助力建造伦蒂尼恩，终迎来统一不列颠的第一位国王。  
性格严苛时严厉、安抚时温柔；最不能容许的是背叛——包括自己内心的背叛。

**资料 5 · 雨之国魔女的故事（Ⅰ）**  
乐园阿瓦隆派出、用以纠正不列颠的乐园妖精，幼体漂至最北奥克尼。雨之氏族明知藏匿她会暴露先祖之罪，仍因怜悯而抚养。王妃视如己出，赐名「梣」（与世界树同名），只为给她知识与回忆，免她日后茫然上路。  
她明白使命近乎「终结不列颠」，却为雨之氏族的温柔所感，在空无一人的图书室里，于雨声与灰空下，开始摸索：能否不终结岛屿，而是重新开始、拯救为罪感所苦的妖精——做着「理想之国」的梦。

**资料 6 · 雨之国魔女的故事（Ⅱ）**  
16 岁那天，畏惧断罪的其他氏族同盟攻入奥克尼。雨之氏族全灭；挺身假扮乐园妖精掩护她的，是王妃亲生女儿。  
幸存的她为实现「没有纷争的和平不列颠」之托付，压下憎恨，以救世妖精身份南下。初至本土时因丧痛失神，一度像童话里的「邪恶魔女」：「除雨之氏族外我全讨厌……若要我帮助，就付比生命更贵的代价。」  
千年旅途后，同伴与目的都明确了，她从「坏魔女」模式毕业——魔女梣的故事至此结束，之后便是救世主的故事。

## Lostbelt No.6 剧情概要（终局相关）

### 起源与第二轮妖精历

本名薇薇安的乐园妖精，被星之内海送往不列颠，使命是促使带原罪的妖精赎罪，并促成异闻带毁灭。雨之氏族藏匿抚养她，却遭风、土、牙、翅四族屠灭；第一轮中她亦死去，大灾厄后不列颠灭亡。

隐匿者贝里尔·伽特抵达荒芜的异闻带后，随手召唤泛人类史摩根。泛人类史摩根解析灵子转移，将荒芜景象与自身情报托付给过去的薇薇安后消亡——「妖精历第二轮」由此开始。  
第二轮的她放弃「抹除不列颠」的乐园使命，选择作为「摩根」活下去，踏上救世之旅，后化名「梣」。

### 救世、圆桌与冬之女王

数千年间：祓除灾厄、召唤贤人格里姆学魔术、与托托洛特等同行；灾厄过后却屡遭流放与刑罚，只得入棺沉睡、灾时再醒。仲裁夏之战争、促成六氏族体制；秋之战争中弟子尤瑟一度统一，却在加冕时被毒杀，伦蒂尼恩崩溃。  
绝望的她不再「拯救妖精」，只守护岛屿本身：抽干空想树魔力、复生已灭的妖精一代，自奥克尼发动「冬之战争」，加冕为女王摩根，开启女王历，以光之壁隔绝外界，暴政维持约两千年——实为以高压阻止妖精因「有趣」而虐杀人类、自取灭亡。

### 迦勒底到来与末路

女王历 2017：迦勒底抵达，与第二位乐园妖精阿尔托莉雅·卡斯特同行。摩根用水镜将玛修送回妖精历 400 年前后，使其得以与梣一行探寻真相。  
会见后，她宣判泛人类史「就在这凄惨境况下毁灭吧」，同时对卡斯特说：若要救不列颠，就打倒她、夺走王座；在敲响巡礼之钟前，不会视其为敌。

巡礼完成后，新圆桌军与王之氏族进攻卡美洛。分身尽灭后，本体于王座前因误会承受伍德沃斯一击；又因人质而露出破绽。欧若拉远程煽动：一切灾厄源头皆是摩根。被煽动的妖精群殴致死。  
临终她仍想回到王座——离开维持魔力之人，便无人压制科尔努诺斯，不列颠将真正毁灭。芭万·希绝望地自天台跃入大洞……

> 「快，住手——让我，回玉座……！我已经，不想再，失去，不列颠了……！」

## 一句话

她曾是图书室里梦见理想国的雨之国少女，曾是千年旅途中的救世主梣，最终成为以暴政死守「自己的不列颠」的冬之女王——被自己一心守护的国度亲手杀死，至死仍想坐回那把压制灾厄的王座。
