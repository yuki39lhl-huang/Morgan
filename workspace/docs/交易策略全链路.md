## 一、一句话

每 15 秒先管出场；每 60 秒算指标 → 评分（只开多、震荡不开）→ 过风控 → 可选 AI 否决/加减分 → 市价开仓并挂交易所 Algo；本地早保本/trailing/ATR/48h 超时与 Algo **双轨**出场；平仓前先撤 Algo；归因进 SQLite。

## 四、开仓流程

### 4.1 市场状态 `detect_regime`

| 条件 | regime |
| --- | --- |
| ATR% > 5% | `volatile` |
| \|EMA 斜率\| > 0.5% | `trending` |
| 其它 | `ranging`（不开新仓） |

### 4.2 评分 `calc_score`

| 维 | 分 | 规则 |
| --- | --- | --- |
| 突破 | 40 | 价破阻力/支撑（容差 0.1%） |
| 量能 | 30 / 15 | 相对 20 均量 >1.5× / >1.2× |
| ATR | 20 | 0.5% &lt; atr% &lt; 3% |
| BTC 大盘 | +10 / −5 | EMA20 vs EMA60 同向加分 |
| 情绪 | ≤+15 | 恐贪 + 资金费率（测试网费率） |

门槛：trending 70 / volatile 90；SOL +10。`allow_short=false` 时空头直接 `NONE`。

### 4.3 风控闸门（任一不过则跳过）

1. **熔断**（已开）：日亏 / 100U &lt; −10% → **停到次日 00:00**（不再 4h 续判）；连亏 3 笔停 2h。只拦新开仓。  
2. **单币上限** `max_positions_for_symbol`：0=停开；≥上限跳过。  
3. 同向冷却 300s（SOL 600s）；反向立即。  
4. 已满 4 仓。  
5. 新闻黑名单暂停：配置在，但 `process_news` **无人调用**（死代码，不生效）。

### 4.4 AI（可选）

调用：有开仓信号且未满仓；或 `has_major_news`（子串关键词，粗糙）；或浮亏 &lt; −2% 且冷却 ≥2h。  

否决：AI 震荡 → `ai_range`；反向且置信 ≥0.7 → `ai_conflict`。  
加减分：同向 +5 / 反向低置信 −3。

整点另有**新闻影子**（`ai_scans.news_*`）与 **market_ext**，**不进开仓**。

### 4.5 下单与记录

`calc_tp_sl` → 市价开仓 + Algo TP/SL → `record_open` → 本地 JSON + 冷却。

## 五、出场流程

优先级大致：**本地硬 TP/SL → 超时 → 早保本/移动止盈改 SL → ATR 动态 SL**；交易所 Algo 可能抢先，靠回填闭环。

| 层 | 触发 | 行为 |
| --- | --- | --- |
| 硬止盈 TP1 | 价到 `tp1_price` | 全平 |
| 硬止损 SL | 价到 `sl_price` | 全平 |
| **早保本** | 峰值浮盈 ≥ 1.5% | 止损挪到成本 +0.5%（只收紧） |
| 超时 | ≥ 48h | 市价「超时退出」 |
| 移动止盈 | 浮盈达 TP 的 50%/75% | 收紧本地 SL 并同步交易所 |
| ATR 动态 | 未触发早保本/trailing 首档 | 按新 ATR 重算 SL |
| Algo 成交 | 交易所先平 | `reconcile_vanished_positions` 补记 |

**平仓顺序（10-12）**：先撤该币全部 Algo → 重读实仓 → 数量**向下取整** → `reduceOnly`；仍 −2022 再撤再试；还失败且仓还在才降级普通单；无同向仓绝不下普通单（防反手）。

## 六、止盈止损公式

```text
tp_pct = max(0.04, min(atr_pct × 2.0, 0.15))
sl_pct = clamp(atr_pct × mult, 0.02, 0.15)   # ATR<4% ×2.0；≥4% ×2.5
```

移动止盈：峰值进度 ≥50%×TP → 回撤 20%；≥75% → 25%。  
早保本：`breakeven.trigger_pct=0.015` / `lock_pct=0.005`。
