```text
┌─ 每 15s ─────────────────────────────────────────────────────┐
│ 保证金保护 → 取价 → 本地 TP1/SL → 48h 超时 → 移动止盈 → 落盘   │
├─ 每 60s (tick%4==0) ─────────────────────────────────────────┤
```

## 四、开仓流程（信号 → 下单）

### 4.1 市场状态 `detect_regime`

| 条件 | regime |
| --- | --- |
| ATR% > 5% | `volatile` |
| \|EMA 斜率\| > 0.5% | `trending` |
| 其它 | `ranging` |

### 4.2 评分 `calc_score`（五维）

| 维 | 分 | 规则 |
| --- | --- | --- |
| 突破 | 40 | 价破阻力/支撑（容差 0.1%） |
| 量能 | 30 / 15 | 相对 20 均量 >1.5× / >1.2× |
| ATR | 20 | 0.5% &lt; atr% &lt; 3% |
| BTC 大盘 | +10 / −5 | BTC EMA20 vs EMA60 同向加分 |
| 情绪 | ≤+15 | 恐贪 + 资金费率 |

**开仓门槛**（另：SOL +10）：

| regime | 门槛 |
| --- | --- |
| trending | 70 |
| ranging | 80 |
| volatile | 90 |

多空分更高且 ≥ 门槛 → `LONG`/`SHORT`，否则 `NONE`。

### 4.3 风控闸门（任一不过则跳过）

1. 熔断 `circuit_breaker_enabled`（现网 **false**，日亏/连亏不生效）  
2. 同向冷却 300s（SOL 600s）；反向立即  
3. 新闻黑名单命中 → 该币暂停 2h  
4. 已满 4 仓 / API 或本地已有该币仓  

### 4.4 AI（可选）

**何时调用**（`ai_trigger`）：

- 有开仓信号且未满仓；或  
- 重大新闻；或  
- 持仓浮亏 &lt; −2% 且冷却 ≥ 2h  

**否决（不开仓，记 `vetoes`）**：

- AI 说震荡 → `ai_range`  
- AI 反向且置信度 ≥ 0.7 → `ai_conflict`  

**加减分（不开仓否决时）**：同向 +5 / 反向低置信 −3（`ai_score`）。

### 4.5 下单与记录

1. `calc_tp_sl` → TP1 / SL / `tp_pct`  
2. `place_order` 市价 + 挂 Algo `TAKE_PROFIT_MARKET` / `STOP_MARKET`  
3. 成功 → `record_open` → `trades` 表；写本地 `crypto_positions.json`；记冷却

## 五、出场流程（多层，可并存）

优先级大致为：**本地硬 TP/SL → 超时 → 移动止盈改 SL → ATR 动态 SL**；交易所 Algo 可能抢先成交，靠回填闭环。

| 层 | 触发 | 行为 |
| --- | --- | --- |
| 硬止盈 TP1 | 价到 `tp1_price` | 全平（无 TP2） |
| 硬止损 SL | 价到 `sl_price` | 全平 |
| 超时 | 持仓 ≥ 48h 未触 TP/SL | 市价「超时退出」 |
| 移动止盈 | 浮盈达 TP 的 50%/75%/100% | 收紧本地 SL（并同步交易所） |
| ATR 动态止损 | 未进 trailing 首档 | 按新 ATR 重算 SL（冷却 300s） |
| Algo 成交 | 交易所先平 | `reconcile_vanished_positions` 补记 close |
| 迷你仓 | API 量 &lt; 80% 标准 | 关掉再按标准量重开 |

平仓 `reduceOnly` 若被拒（−2022）会降级普通市价，仍应记库。

## 六、止盈止损公式（现网）

**止盈**

```text
tp_pct = max(0.04, min(atr_pct × 2.0, 0.15))
```

**止损**（地板 2%、天花板 15%）

| ATR% | 倍数 |
| --- | --- |
| &lt; 2% | ×2.0 |
| &lt; 4% | ×2.0 |
| ≥ 4% | ×2.5 |

```text
sl_pct = clamp(atr_pct × mult, 0.02, 0.15)
```

**移动止盈**（相对本次 `tp_pct`）

| 峰值进度 | SL 回撤 |
| --- | --- |
| ≥ 50%×TP | peak × 20% |
| ≥ 75%×TP | peak × 25% |
| ≥ 100%×TP | 本地 SL≈现价（常与硬 TP Algo 抢单） |

配置键：`base_tp_pct` / `min_sl_pct` / `atr_sl_tiers` / `trailing_tiers` / `timeout_exit` / `leverage`。
