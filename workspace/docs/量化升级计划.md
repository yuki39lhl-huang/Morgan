## 二、决策原则

1. **用数据说话**：每阶段先出报告再推进  
2. **单点可回滚**  
3. **不碰稳定引擎**：新能力先并轨  
4. **风险分级**：纯记录随时做；改决策须过验收  
5. **配置可信优先于调参**：先保证改 JSON 真生效（2.9 已完成），再谈改数值
