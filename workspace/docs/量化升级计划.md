### 现在该做什么

1. **盯数据质量**：新开仓配对率、SSL 假清空、超时是否只打「真超 48h」  
2. **周报**：按 regime / 币种 / 平仓原因拆开  
3. **可配对 ≥150～200** → 特征权重 / 精简 ETH·BNB / 动态仓位  
4. **2.5 验收后再评离场**：早保本 P1 → 趋势止盈 P2 → AI 离场 P3  
5. **特征（验收后、模型前）**：OI / 费率极值 / BTC 主导；新闻做成可验证特征。广场 / TG **不进主评分**

**顺序**：数据质量 → 配置可信（已基本达标）→ 证明 edge → 仓位/离场 / 结构化特征 → 模型 → 实盘。

1. **用数据说话**：每阶段先出报告再推进

5. **配置可信优先于调参**：先保证改 JSON 真生效（2.9 已完成），再谈改数值

**密钥槽（2026-09-27，只准备、不切换）**

运行中的下单只读 `secrets.json` 的 `binance_api_key` / `binance_api_secret`，并且 `config.json` 的 `binance_testnet=true`。实盘密钥在 `binance_mainnet_api_key` / `binance_mainnet_api_secret`，由 `BinanceEnvConfig` 读出但不参与下单。改这两项不会让测试网变成实盘。2026-09-27 已写入；币安页面的 IP 框当时仍是空的，须填服务器出口 IP 并保存后这把密钥才可用。

币安后台创建时：

| 项 | 要 | 不要 |
| --- | --- | --- |
| 类型 | 系统生成 HMAC | 把密钥发给第三方或写进仓库 |
| 权限 | 允许读取、允许合约 | 「启用现货、杠杆和股票」是现货杠杆，不是合约倍数。合约 10 倍靠「允许合约」。不要万向划转、不要预测交易 |
| IP | 只填这台机器出口 IP。2026-09-27 查到 `38.92.27.172`（`curl -4 ifconfig.me`）。这是服务器出去的地址，不是你 SSH 登录用的家里 IP。云主机一般稳定，换机器或运营商改地址后要改白名单，不用重建 API | 「无限制」 |
| 币对白名单 | 弹窗是现货及杠杆。可填 `BTC/USDT ETH/USDT SOL/USDT BNB/USDT DOT/USDT LINK/USDT XRP/USDT`，与 `symbols` 同名。它不限制 U 本位永续。换币点「编辑」，不用新建 | 不要为此去勾「启用现货、杠杆」 |

页面上若取消了「默认安全控制措施」，等于放宽限制，实盘前应改回受信任 IP。密钥只写在本机 `secrets.json`，不要写进 `config.yaml` 或 git。

**切实盘顺序（单独一天做，不与调参绑在一起）**
