## 三、待办

- [ ] 10-12 评估早保本 + 停空单；决定 BTC/BNB（ETH）去留（Phase 2.8 S1）
- [ ] AI 否决线 0.7→0.65：离线回归里 AI 同向两段方向相反，证据不足，先不动
- [ ] 回测扫开仓门槛（`backtester.py` 不模拟移动止盈，出场另用 K 线重放）
- [ ] 空单：查清亏损原因或行情转跌后，再考虑 `allow_short=true`
- [ ] 记录链路验收：新单配对 >95%；无假清空；超时只打满 48h 的仓
- [ ] `vetoes` 反事实是否够下结论（<30 仅参考）
- [ ] 新闻影子对照（10-04 起记录）：每小时扫描时，有相关新闻就带新闻再问一次 AI，结果在 `ai_scans.news_*`，开仓不看。1～2 周后跑 `analyze_features.compute_news_shadow_hit()`，重点看「分歧」行，带新闻的命中率明显更高才考虑接进开仓
- [ ] 外部数据（10-04 起记录）：`market_ext` 表每小时存 OKX 真实资金费率、持仓量、1h 持仓量变化、BTC 市占率、全市场 24h 市值变化。攒 2～3 周后进离线回归；开仓时刻按最近一个整点 join。主评分里的资金费率目前来自测试网，不是真实市场
- [ ] 币安广场、TG 不进主评分
- [ ] 配置收尾（按需）：`detect_regime` 门槛、`recvWindow`、回测手续费、突破容差 0.1%
- [ ] 负面新闻暂停从未接通：`NewsFilter.process_news` 没人调用，`news_blacklist` / `news_suspend_hours` 不起作用；函数里内层 `sym` 覆盖外层，接通会把所有币一起暂停。要用先修再接，算一次策略改动。同一个类里 `has_major_news` 用子串匹配（"sec" 命中 Securities、"ban" 命中 Bank），也不分币种，一起修

**密钥**：下单只读 `secrets.json` 的 `binance_api_key` / `binance_api_secret`，且 `binance_testnet=true`。实盘密钥已存在 `binance_mainnet_*`，只存放、不参与下单。币安后台要求：

- 权限只开「读取 + 合约」，不开万向划转

**切换顺序（单独一天做，不和调参放在一起）**

4. 第一天只放 1 仓，对过一笔开平（数量、两张 Algo、平仓记账）再放开到 4。
