## 五、实盘迁移（未开始）

测试网账户约 10000U 不参与计算。实盘本金 **100U USDT**：单仓保证金约 20U，名义约 200U，4 仓占约 80U，留约 20U。策略不会往亏损仓加码；只有平仓被 `-4164` 拒时补 5U 保证金，或名义太小时先垫量再平。

**密钥**：下单只读 `secrets.json` 的 `binance_api_key` / `binance_api_secret`，且 `binance_testnet=true`。实盘密钥已存在 `binance_mainnet_*`，只存放、不参与下单。币安后台要求：

- 系统生成 HMAC
- 权限只开「读取 + 合约」，不开万向划转
- IP 白名单只填本机出口 `38.92.27.172`，换机器后要改
- 币对白名单只管现货杠杆，不限制 U 本位永续

密钥不进 git 和 `config.yaml`。

**切换顺序（单独一天做，不和调参放在一起）**

1. 满足上线条件：最近两周扣费为正；记录链路验收通过。
2. 切换：`binance_api_key` 换成主网、`binance_testnet=false`、基址改 `fapi.binance.com`，重启 monitor。
3. 确认 100U / 20% / 10 倍 / 4 仓 / 逐仓 / 熔断开。
4. 第一天只放 1 仓，对过一笔开平（数量、两张 Algo、平仓记账）再放开到 4。
5. 当天不改 TP/SL，不加新特征。
