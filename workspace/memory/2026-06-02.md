## Bug 修复

### 1. binance_auto_trade.py — `reduceOnly` 未传给币安 API
- `place_order()` 函数接受 `reduce_only` 参数但从未放入 `order_params`
- 导致小仓位（如 ETH 0.008）无法平仓：币安要求 notional ≥ $20，reduce_only 可豁免
- **修复**: 在 order_params 中加入 `"reduceOnly": str(reduce_only).lower()`

### 2. crypto_signal_monitor.py — `open_position()` 缺少价格校验
- 当 entry_price=0 时，`100 * 0.20 * 10 / 0 = inf`，会导致异常下单
- **修复**: 在数量计算前加入价格有效性检查（≤0 或 >1,000,000 则拒绝）
