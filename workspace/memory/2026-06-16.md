# 2026-06-16 日志

## 代码改动

### 1. ATR 动态止损（持仓期实时跟跑）
- **文件**：`crypto_signal_monitor.py`
- **新增函数**：`update_atr_dynamic_stops(positions, indicators)` (line ~752)
- **逻辑**：持仓期间每 60s 用当前 ATR 重算止损距离
  - 分层：`<2%ATR→1x / <4%→1.5x / ≥4%→2x`，上限 15%
  - 5 分钟冷却 + 0.1% 变化门槛 + 层级变化才更新 Binance 订单
  - 已进入三档移动止盈（peak ≥ 50% tp）时跳过，避免冲突
- **调用位置**：指标计算完成后 (`if scheduler.should("indicators")`)

### 2. 启动丢 SL 修复
- **文件**：`crypto_signal_monitor.py`
- **问题**：重启时 `calc_tp_sl(entry, direction, {}, {})` 用空指标重建持仓，覆盖了三档移动止盈收紧过的 SL
- **修复**：
  - 加载 old_positions 建索引后合并到新持仓
  - 对比新旧 SL：如果旧 SL 更紧（SHORT: 更低 / LONG: 更高），保留旧的
  - 恢复 peak_pnl、peak_price、tp_pct 字段
  - 如果 old_sl=0 但有 peak_pnl：反推估算 SL（从 peak_price 推算）

### 3. BNB 止损丢失事件
- 第一次 kj 后 BNB SL 从 617.8 变成 639.3 → 639.3 变成 0
- 根因：启动代码 old_sl=0 导致不匹配，submit_initial_algo_orders 跳过，SL 永久丢失
- 修复过程：停 monitor → 手动修 crypto_positions.json → 直接创建 Binance Algo 单 → kj 重启
- 最终 BNB SL 恢复到 617.8
